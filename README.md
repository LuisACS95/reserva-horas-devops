# Sistema de Reserva de Horas - Proyecto DevOps

Este repositorio contiene la solución contenerizada para la plataforma de reserva de horas.

## Instrucciones de Ejecución
1. Clonar este repositorio.
2. Copiar `.env.example` a un nuevo archivo `.env`.
3. Ejecutar en terminal: `docker compose up -d`
4. Acceder en el navegador a `http://localhost:8080`
